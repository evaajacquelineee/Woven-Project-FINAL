🌿 WOVEN — Natural Fiber Fashion Discovery
Live site → evaajacquelineee.github.io/Woven-Project-FINAL

WOVEN is a curated fashion discovery platform for people who want to find clothing made from natural fibers — cotton, linen, hemp, wool, silk — without hours of research. 69% of clothing today is synthetic, but the brands making beautiful natural-fiber alternatives are scattered and invisible next to fast fashion giants. WOVEN lets you browse by aesthetic (Minimalist, Coastal, Quiet Luxury, Streetwear, and more), read plain-language brand profiles, and shop directly — no jargon, no ethics scores, no guilt.

Built from scratch as a solo project for an Entrepreneurship class (Spring 2026). I manually researched and curated 20–25 natural fiber brands, wrote all brand descriptions in an original editorial voice, and developed a responsive mobile-first site in HTML, CSS, and JavaScript hosted on GitHub Pages. I built the tool I wished existed.
